# Registros de decisiones de arquitectura

Los ADR conservan el contexto y las consecuencias de decisiones importantes.

## Proceso

1. Copiar `000-template.md` con el siguiente número disponible.
2. Completar contexto, alternativas, decisión y consecuencias.
3. Abrir un pull request y obtener revisión del equipo.
4. Cambiar el estado a `Aceptada`, `Rechazada` o `Reemplazada`.
5. Si una decisión cambia, crear un ADR nuevo y enlazar ambos.
