# Roles de trabajo

El enunciado propone roles por unidad y permite reasignarlos al cambiar de unidad. Registrar la asignación vigente al inicio de cada etapa; una persona puede cubrir más de una responsabilidad si el equipo lo acuerda.

| Rol                            | Responsabilidad principal en el repositorio                                      |
| ------------------------------ | -------------------------------------------------------------------------------- |
| Arquitectura de proyecto       | Coordinar decisiones, mantener la visión global y aprobar cambios estructurales. |
| Análisis y diseño              | Mantener requisitos, criterios de aceptación y trazabilidad con el diseño.       |
| UI/UX y diseño                 | Diseñar interacciones, accesibilidad, prototipos y validaciones con usuarios.    |
| Desarrollo front/back y diseño | Implementar incrementos acordados, pruebas y documentación técnica.              |

## Revisión de decisiones

- Una persona propone o redacta el cambio.
- Otra persona revisa código y documentación.
- Arquitectura interviene cuando cambia un límite del sistema.
- Análisis confirma la relación con requisitos.
- UI/UX revisa cambios visibles y accesibilidad.

La revisión cruzada reduce la dependencia de una sola persona y deja evidencia del trabajo colaborativo.
