# Alcance de esta preparación

## Incluido ahora

- Estructura de monorepo y límites entre web, API y contratos.
- Configuración reproducible de TypeScript y pnpm.
- Página web mínima de verificación.
- Endpoint de salud mínimo en cada aplicación.
- Prueba automática del endpoint de la API.
- PostgreSQL local opcional sin tablas ni conexión desde la aplicación.
- Automatización de formato, lint, tipos, pruebas, build y CI.
- Guías para colaboración, requisitos, arquitectura y decisiones.

## Deliberadamente no implementado

Los siguientes elementos pertenecen al proyecto del curso y no forman parte de la preparación:

- administración de proyectos, integrantes, cursos, roles o permisos;
- requisitos de usuario y software, hitos, tipos de usuario, módulos y casos de prueba;
- modos estándar y simplificado;
- edición de documentos, imágenes, plantillas o archivos PDF;
- alarmas, estadísticas, matrices, consistencia, bitácora o tareas;
- autenticación única, Educandus, encuestas, Mercado Pago o Flow;
- clonación de proyectos;
- entidades, tablas, migraciones, semillas o repositorios de datos;
- interfaz definitiva, nombre comercial, identidad visual o logotipo.

## Mapa de trabajo futuro

El enunciado preliminar agrupa diez componentes: administración general, elementos del proyecto, documentos, generación PDF, alarmas, estadísticas, matrices de trazado, consistencia, bitácora y tareas. Este listado sirve como mapa inicial, no como backlog aprobado.

Antes de implementar cada componente, el equipo debe:

1. asociarlo a requisitos aprobados en la plantilla oficial;
2. definir criterios de aceptación y prioridad;
3. revisar dependencias y riesgos;
4. acordar el diseño y registrar decisiones relevantes;
5. convertirlo en issues pequeños y verificables.

## Control de cambios

El enunciado indica que puede recibir cambios. Cuando ocurra:

1. registrar fecha y fuente de la aclaración;
2. actualizar requisitos afectados;
3. revisar trazabilidad, arquitectura y pruebas;
4. reflejar el ajuste en issues o hitos;
5. evitar modificar alcance solo por conversaciones no confirmadas.
